# AFP website

Source for the Agent Files Protocol (AFP) website.

**Status: not live.** The domain `agentfiles.org` is used as a placeholder canonical in `index.html`, `robots.txt` and `sitemap.xml`. It is **not registered**. There is no `CNAME` file. Update those three files if a different domain is chosen.

The site is one static page: the problem, the idea, the five operations, backends and deployment topologies, AMP integration, and security notes. It has no analytics tag.

## Specification

The protocol specification lives at [agentmessaging/agent-files](https://github.com/agentmessaging/agent-files) (v0.1 draft). That repository is not created yet at the time of writing, so the GitHub links on the page do not resolve until it is.
